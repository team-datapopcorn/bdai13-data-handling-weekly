# 10주차 · 과제 1 리뷰 + 자동화 사고 — 반복을 분해한다

## 오늘 얻어가는 것

과제 1을 되짚어보고, 이후 6주(11~16주)에서 다룰 "반복 작업 자동화"의 기본 틀을 잡는다.

## 준비된 데이터

없음. 자기가 실제로 반복하는 작업을 재료로 쓴다(학교 과제, 동아리 활동, 아르바이트 등 무엇이든).

## 해야 할 일

1. **과제 1 리뷰** — 제출한 정리 코드와 검증 체크리스트를 다시 보고, 놓쳤던 부분을 찾는다.
2. **자기 반복 작업 하나를 고른다** — 매주/매달 손으로 반복하는 데이터 작업(예: 동아리 회비 정산, 설문 결과 집계).
3. **트리거·입력·처리·출력·기록 5단계로 쪼갠다.**
   - 트리거: 언제/무엇이 계기가 되어 이 작업을 시작하나
   - 입력: 어떤 데이터를 어디서 가져오나
   - 처리: 어떤 계산·정제를 하나
   - 출력: 결과를 어떤 형태로 누구에게 전달하나
   - 기록: 이 작업을 했다는 걸 어떻게 남기나(로그, 이력)
4. **어느 단계가 자동화하기 쉬운지 표시한다** — 5단계 중 코드로 대체 가능한 부분과, 사람 판단이 꼭 필요한 부분을 구분한다.

## 산출물

- 과제 1 회고 3~5줄
- 자기 반복 작업의 5단계 분해표
- "이 중 어디부터 자동화할까" 우선순위 메모

## 검증 체크

- [ ] 5단계 각각에 실제 도구/파일 이름이 구체적으로 적혀 있는가(추상적 설명이 아니라)
- [ ] 사람 판단이 필요한 단계를 억지로 자동화 대상에 넣지 않았는가
