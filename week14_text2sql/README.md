# 14주차 · Text2SQL과 분석 자동화

## 오늘 얻어가는 것

자연어 질문을 AI가 SQL로 바꿔주는 흐름을 실습하고, 결과를 검증·테스트 쿼리로 확인하는 습관을 들인다.

## 준비된 데이터

5·6주차와 같은 **Postgres 실습 서버**(`bdai13` 스키마)를 그대로 재사용한다. 접속 방법은 `../week05_sql_aggregation/README.md`의 "방법 A" 참고.

## 해야 할 일

1. **자연어 질문 5개를 준비한다** — 예: "지난 3개월 동안 가장 많이 팔린 상품은?", "지역별 평균 주문 금액은?", "가입 후 한 번도 로그인 안 한 고객은 몇 명?"
2. **AI에게 질문을 그대로 던지고 SQL로 바꾸게 한다** — 스키마(테이블·컬럼 목록)를 함께 알려줘야 정확도가 올라간다는 걸 직접 확인한다(스키마 안 주고 vs 주고 결과 비교).
3. **테스트 쿼리로 결과를 검증한다** — AI가 만든 쿼리 결과를, 똑같은 질문을 더 단순한 쿼리 2~3단계로 쪼개 손으로 검산한 값과 대조한다.
4. **틀리기 쉬운 질문 유형을 정리한다** — "평균"을 낼 때 분모에 무엇을 넣을지 애매한 질문, 기간 조건("지난 3개월")의 기준일 해석이 갈리는 질문 등 AI가 자주 다르게 해석하는 패턴을 모은다.

## 산출물

- 자연어 질문 5개 + AI가 만든 SQL + 실행 결과
- 스키마 제공 여부에 따른 정확도 비교
- 검증 쿼리와 대조 결과

## 검증 체크

- [ ] 각 SQL 결과를 최소 한 번은 다른 방식으로 재계산해 대조했는가
- [ ] "지난 3개월" 같은 상대 기간 표현의 기준일을 명시했는가
- [ ] AI가 존재하지 않는 컬럼을 지어내지 않았는가(스키마와 대조)
