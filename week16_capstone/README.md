# 16주차 · 과제 2 발표와 회고

## 오늘 얻어가는 것

과제 2 결과물을 포트폴리오 관점으로 발표하고, 16주 전체를 회고한다.

## 준비된 데이터

없음 — 이번 주는 각자의 과제 2 결과물이 재료다(11~15주차 데이터를 써서 만든 자기 산출물).

## 해야 할 일

1. **발표 자료를 정리한다** — 문제 정의 → 데이터 처리 흐름 → 결과 해석 → 한계 순서로 5분 내외 분량.
2. **재현성을 마지막으로 확인한다** — README만 보고 남이 실행해도 같은 결과가 나오는지 8주차 때처럼 다시 점검한다.
3. **한계와 다음 단계를 적는다** — 이번 프로젝트에서 데이터·시간 제약으로 못 다룬 부분, 더 해보고 싶은 방향.
4. **16주 회고** — 1주차부터 지금까지 "AI 결과를 의심하고 검증한 경험" 중 가장 인상 깊었던 순간 하나를 고른다.
5. **다음 학습 로드맵을 그린다** — 이 과정 이후 더 파고들고 싶은 주제(SQL 심화, 대용량 처리, 특정 도메인 분석 등)를 정한다.

## 산출물

- 과제 2 발표 자료
- 재현성 최종 점검 결과
- 16주 회고 + 다음 학습 로드맵
