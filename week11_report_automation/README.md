# 11주차 · 반복 리포트 자동화(Python) — 한 번 만들어 재실행 + 과제 2 안내

## 오늘 얻어가는 것

매달 손으로 반복할 표·차트·요약을, 한 번 만들면 다음 달에도 그대로 돌아가는 스크립트로 만든다.

## 준비된 데이터

`monthly/2026-01.csv` ~ `2026-06.csv` — 카라멜팝콘 상품별 월간 판매 요약(`product_id`, `product_name`, `category`, `units_sold`, `revenue`).

> **함정 주의:** 2026-04부터 `channel`(온라인/오프라인/제휴) 컬럼이 새로 추가됐다. "매달 파일 모양이 똑같을 것"이라고 가정한 스크립트는 4월 파일부터 깨지거나 그 컬럼을 조용히 무시한다.

## 해야 할 일

1. **한 달치로 먼저 리포트를 짠다** — `2026-01.csv`를 읽어 카테고리별 매출 합계 표 + 막대 차트 + "이번 달 매출 1위 상품" 한 줄 요약을 만든다.
2. **AI에게 "여러 달을 한 번에 처리하게 해줘"를 시킨다** — `monthly/` 폴더의 모든 CSV를 순회하며 같은 리포트를 만드는 스크립트로 확장한다.
3. **스키마 변화를 검증한다** — 6개월치를 다 돌렸을 때 4월부터 컬럼이 늘어난 걸 스크립트가 알아채는지 확인한다. 에러 없이 조용히 넘어갔다면 그게 문제다 — 명시적으로 처리(있으면 쓰고, 없으면 기본값)하도록 고친다.
4. **재실행 가능한 형태로 저장한다** — 리포트 생성 스크립트 1개 + 출력(표·차트 이미지 또는 HTML) 6개월치.
5. **과제 2 안내를 확인한다** — 입력→집계→해석까지 이어지는 흐름을 재실행 가능한 자산으로 만드는 게 과제 2다. 이번 스크립트가 그 출발점이 될 수 있다.

## 산출물

- 월별 리포트 생성 스크립트(모든 달에 재사용 가능)
- 6개월치 리포트 결과물
- 스키마 변화(4월 `channel` 컬럼)를 어떻게 처리했는지 메모

## 검증 체크

- [ ] 스크립트를 고치지 않고 7번째 달 CSV를 넣어도 돌아가는가
- [ ] `channel` 컬럼이 있는 달과 없는 달을 스크립트가 구분해서 처리하는가
- [ ] 리포트 숫자를 원본 CSV와 수동으로 한 번 대조했는가
