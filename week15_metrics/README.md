# 15주차 · 지표로 마무리 — OMTM·KPI·데이터 품질

## 오늘 얻어가는 것

분석을 숫자 하나(OMTM)와 몇 개의 KPI로 정의하고, 그 숫자를 믿을 수 있는지(데이터 품질) 점검한다.

## 준비된 데이터

`../week11_report_automation/monthly/`의 6개월치 데이터를 재사용한다.

## 해야 할 일

1. **카라멜팝콘의 OMTM(One Metric That Matters)을 하나 정한다** — 예: "월 매출", "카테고리당 평균 판매 수량". 왜 그 지표를 골랐는지 이유를 적는다.
2. **보조 KPI 2~3개를 정한다** — OMTM을 설명하거나 견제하는 지표(예: 매출이 늘어도 특정 카테고리에만 쏠리면 위험하다는 걸 보여주는 카테고리 다양성 지표).
3. **6개월치로 지표를 계산한다** — 11주차 스크립트를 재사용해 월별 OMTM·KPI 추이를 표/차트로 만든다.
4. **데이터 품질을 점검한다** — 4월부터 생긴 `channel` 컬럼처럼 스키마가 바뀐 지점에서 지표 계산이 흔들리지 않았는지, 결측·이상치가 지표를 왜곡하지 않았는지 확인한다.
5. **과제 2 중간 점검** — 지금까지의 자동화 스크립트가 과제 2의 뼈대로 쓸 만한지 점검하고 부족한 부분을 목록으로 정리한다.

## 산출물

- OMTM 정의문(무엇을, 왜 골랐는지)
- 월별 OMTM·KPI 추이 표/차트
- 데이터 품질 점검 결과(스키마 변화·결측·이상치 영향)
- 과제 2 중간 점검 목록

## 검증 체크

- [ ] OMTM을 고른 이유가 "측정하기 쉬워서"가 아니라 목표와 연결돼 있는가
- [ ] 스키마가 바뀐 달(4월)의 지표가 다른 달과 비교 가능한 방식으로 계산됐는가
- [ ] 지표가 한 개의 극단값(이상치)에 크게 흔들리지 않는지 확인했는가
