# 7주차 · 벡터화 vs 반복문 — 왜 빠른지, 맞는지

## 오늘 얻어가는 것

AI가 준 코드가 벡터화됐는지 반복문인지 구분하고, 속도 차이와 정확성을 직접 잰다.

## 준비된 데이터

`transactions_large.csv` — 30만 행. 컬럼: `txn_id`, `customer_id`, `product_id`, `qty`, `unit_price`, `region`.

## 해야 할 일

1. **"거래별 매출(qty × unit_price)을 구해줘"를 AI에게 두 가지 방식으로 시킨다.**
   - 반복문 버전: `for` 루프 또는 `iterrows()`로 한 행씩 계산
   - 벡터화 버전: `df["qty"] * df["unit_price"]`
2. **속도를 잰다** — `time.time()` 또는 `%timeit`으로 두 버전의 실행 시간을 비교한다. 300,000행에서 몇 배 차이 나는지 기록한다.
3. **결과가 똑같은지 검증한다** — 속도만 보고 넘어가지 않는다. 두 버전의 매출 합계, 첫 5행 값이 완전히 같은지 대조한다.
4. **지역(`region`)별 매출 집계도 벡터화로 다시 해본다** — `groupby("region")["매출"].sum()`. 반복문으로 같은 걸 짜면 얼마나 느려지는지도 확인(선택, 시간 되면).

## 산출물

- 반복문 버전 / 벡터화 버전 코드 두 개
- 실행 시간 비교표
- 두 결과가 일치하는지 확인한 코드와 출력

## 검증 체크

- [ ] 반복문·벡터화 결과의 합계가 완전히 같은가
- [ ] 실행 시간을 잴 때 워밍업(첫 실행) 비용을 빼고 쟀는가
- [ ] `region` 표기가 통일돼 있어 집계가 갈라지지 않았는가
