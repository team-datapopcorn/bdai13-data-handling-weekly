# 13주차 · AI 에이전트로 데이터 작업: Claude Code

## 오늘 얻어가는 것

Claude Code 같은 AI 에이전트에게 전처리·분석을 맡기고, 결과를 검증하는 루틴을 실습한다(데모 위주, 선택 실습).

## 준비된 데이터

`messy_sales_raw.csv` — 일부러 지저분하게 만든 카라멜팝콘 주문 원본. 컬럼: `주문id`, `상품명`, `카테고리`, `수량`, `단가`, `지역`, `주문일`.

지저분한 지점(미리 알려주지 않고 학생이 찾게 해도 됨):
- 상품명이 군데군데 비어 있다(결측)
- 지역 표기가 `서울`/`SEOUL`/`seoul`처럼 섞여 있다
- 주문일 형식이 `YYYY-MM-DD`와 `YYYY/MM/DD`로 섞여 있다
- 완전히 같은 행이 중복으로 몇 개 끼어 있다

## 해야 할 일

1. **Claude Code(또는 같은 종류의 AI 에이전트)에게 정제를 맡긴다** — "이 CSV를 분석 가능한 형태로 정리해줘"처럼 자연어로 시킨다.
2. **에이전트가 실제로 무엇을 고쳤는지 diff로 확인한다** — 결측을 어떻게 처리했는지(삭제/채움), 지역 표기를 어떻게 통일했는지, 날짜를 어떻게 맞췄는지, 중복을 지웠는지.
3. **검증 루틴을 돌린다** — 정제 전후 행 수, 결측치 개수, 지역 종류 개수, 중복 행 개수를 비교해 표로 만든다.
4. **에이전트가 놓친 게 있는지 확인한다** — 4가지 함정(결측·표기 불일치·날짜 형식·중복) 중 몇 개를 실제로 잡았는지 체크한다.

## 산출물

- 정제 전/후 CSV
- 에이전트에게 준 프롬프트와 받은 코드
- 정제 전후 비교표(행 수·결측·지역 종류·중복)

## 검증 체크

- [ ] 지역 표기가 하나로 통일됐는가(대소문자·한영 혼용 없음)
- [ ] 날짜가 전부 같은 형식으로 파싱되는가
- [ ] 중복 행이 실제로 사라졌는가(행 수로 확인)
- [ ] 결측 처리 방식(삭제 vs 채움)을 선택한 이유를 설명할 수 있는가
