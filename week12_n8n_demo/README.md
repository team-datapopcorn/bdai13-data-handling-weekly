# 12주차 · 노코드 파이프라인 데모: n8n

## 오늘 얻어가는 것

수집→정제→리포트→알림까지 이어지는 흐름을 코드 없이 노드로 조립하는 걸 강사 시연으로 본다. 데모 위주 회차라 선택 실습이다.

## 준비된 데이터

`../week11_report_automation/monthly/`의 월별 CSV를 그대로 재사용한다. 새 데이터는 없다.

## 시연 흐름(강사)

1. **수집** — Schedule 트리거 또는 수동 트리거로 시작해, `monthly/` 폴더의 CSV(또는 구글시트에 올려둔 사본)를 읽어온다.
2. **정제** — Function/Code 노드에서 11주차와 같은 집계(카테고리별 매출 합계)를 수행한다.
3. **리포트** — 결과를 표 형태로 정리해 구글시트나 이메일 본문에 넣는다.
4. **알림** — Slack(또는 이메일) 노드로 "이번 달 리포트 완성" 메시지를 보낸다.

## 선택 실습(학생)

1. n8n 계정을 만들고 위 흐름 중 "수집 → 정제" 두 단계만 따라 만들어본다.
2. 11주차에 Python으로 짠 스크립트와 비교해 — 노코드가 유리한 지점(빠른 조립, 시각적 흐름)과 불리한 지점(복잡한 로직, 버전 관리)을 각각 하나씩 적어본다.

## 산출물(선택)

- n8n 워크플로우 캡처 또는 export(.json)
- 코드 방식(11주차) vs 노코드 방식(n8n) 비교 메모 3줄

## 검증 체크(선택 실습 시)

- [ ] 알림에 찍힌 숫자가 원본 CSV 집계와 일치하는가
